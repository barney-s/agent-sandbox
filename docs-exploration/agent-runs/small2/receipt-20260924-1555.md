## Deployment Plan: small2 (kOps on GCP)

### Target Cloud Resources
- **GCS State Store Bucket**: `gs://kops-state-as-small2` (Region: `us-central1`, Uniform Bucket-Level Access enabled, labeled `repo-agent-instance=as-small2`)
- **kOps Gossip Cluster**: `as-small2.k8s.local`
- **GCE Compute Instances** (`us-central1-a`):
  - 1 x Control Plane VM (`control-plane-us-central1-a`, machine type: `n2-standard-4`, root disk: `pd-ssd`)
  - 3 x Worker Node VMs (`nodes-us-central1-a`, machine type: `n2-standard-4`, root disk: `pd-ssd`)
- **GCP Networking**: Dedicated VPC network, subnet, and firewall rules created by kOps for `as-small2.k8s.local`
- **GCR Container Images**: `gcr.io/barni-cnrm-20260529/as-small2/*` (built & pushed via `./dev/tools/push-images`)
- **Kubernetes Workloads**: Namespace `agent-sandbox-system`, CRDs, `agent-sandbox-controller` deployment, and extension controllers (deployed via `./dev/tools/deploy-to-kube --extensions`)

### Estimated Cost

- **Object Storage (GCS)**: State store bucket <$0.01/day
- **Total Runtime Cost**: ~$0.85/hour while active. All resources are deleted upon running `teardown.sh`.

### Highlights for Owner Review in `deploy.sh`
1. **kOps Installation**: `deploy.sh` checks for `kops` in PATH and automatically installs `k8s.io/kops/cmd/kops@v1.36.0` to `${HOME}/go/bin` if not found.
2. **UBLA & IAM Bindings**: GCS state store bucket is created with `--uniform-bucket-level-access` and granted `roles/storage.objectAdmin` bindings to prevent auth issues in federated/WIF environments.
3. **Spec Tuning**: Root volume disk types for both control plane and worker nodes are edited to `pd-ssd` to prevent I/O disk bottlenecks during container warm-up.
4. **Validation Timeout**: Includes `kops validate cluster --wait 25m` to allow sufficient time for gossip discovery and Cilium CNI bootstrapping.
5. **Resource Ownership**: All cloud assets use the literal prefix `as-small2` and labels `repo-agent-instance=as-small2`.
