## Deviations from the runbook

1. **no local docker daemon → Cloud Build**:
   - *Cause*: The sandbox execution environment has no local Docker daemon.
   - *Resolution*: Step 3 in `deploy.sh` checks for local Docker and automatically falls back to submitting a build job to Google Cloud Build using `gcr.io/k8s-staging-test-infra/gcb-docker-gcloud`.
2. **Attempt 1: .git excluded during Cloud Build submit → custom ignore file**:
   - *Cause*: Default `gcloud` archive ignores `.git`, causing `utils.git_describe()` to fail.
   - *Resolution*: Submitted Cloud Build with `--ignore-file` omitting `.git` and added `git config --global --add safe.directory '*'` in the build container.
3. **GCS State Bucket UBLA & IAM permissions**:
   - *Cause*: Federated authentication tokens require Uniform Bucket-Level Access (UBLA) and bucket-level IAM binding `roles/storage.objectAdmin`.
   - *Resolution*: Created bucket with `--uniform-bucket-level-access` and bound `roles/storage.objectAdmin` to project owner principals.
4. **Explicit `KUBECONFIG` export**:
   - *Cause*: Test runners and SDK clients rely on `bin/KUBECONFIG` or `$KUBECONFIG`.
   - *Resolution*: Exported kubeconfig to both `bin/KUBECONFIG` and ambient environment.

## Recommended runbook changes

### Step 3 Replacement Text (When Local Docker is Missing)
```sh
# If Docker daemon is unavailable locally, build and push via Google Cloud Build:
cat << EOF > /tmp/cb-ignore
bin/
EOF
cat << EOF > /tmp/cb-build.yaml
steps:
- name: 'gcr.io/k8s-staging-test-infra/gcb-docker-gcloud'
  entrypoint: 'bash'
  args:
  - '-c'
  - |
    git config --global --add safe.directory '*' || true
    python3 ./dev/tools/push-images \
      --image-prefix="${IMAGE_PREFIX}" \
      --image-tag="${IMAGE_TAG}" \
      --images agent-sandbox-controller chrome-sandbox
options:
  machineType: 'E2_HIGHCPU_32'
EOF
gcloud builds submit --project="${PROJECT_ID}" --ignore-file=/tmp/cb-ignore --config=/tmp/cb-build.yaml .
rm -f /tmp/cb-build.yaml /tmp/cb-ignore
```
