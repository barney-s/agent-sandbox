## Notes for Owner Before Deploying

1. **Automatic kOps Compilation:** `kops` is currently not pre-installed in the container PATH; `deploy.sh` contains an automatic on-demand build step (`go install k8s.io/kops/cmd/kops@v1.36.0`) to install it to `${HOME}/go/bin` before executing cluster operations.
2. **Gossip DNS:** The cluster uses `.k8s.local` gossip DNS, requiring no external Route53 or Cloud DNS configuration.
3. **Cluster Validation Timeout:** `kops validate cluster` waits up to 25 minutes to allow Cilium CNI bootstrapping and all 3 worker nodes to enter `Ready` status before manifests are applied.
